Add the genuine SAIXORA Shield release packages to this folder:

saixora-device-shield-windows-x64.exe
saixora-device-shield-android.apk
saixora-staff-shield-android.apk
saixora-admin-shield-android.apk

Then set the matching version and ready: true in ../js/config.js.
The website lists the three Android/Windows product editions as available according to the owner-provided status. Download links remain disabled until files are actually added and tested.
